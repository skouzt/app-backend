# Every dependency is pinned to an exact version.
#
# Ranges meant a rebuild could install something never tested here — and the range
# on dodopayments spanned an API change: this code was written against 1.87.x,
# where localized prices are absent from the SDK, which is why
# scripts/sync_dodo_prices.py calls that endpoint over REST. A float to 1.112 would
# not break the build, it would just quietly mean the running code and the tested
# code are different.
#
# Pins were realigned to the versions this venv actually runs: requirements.txt had
# drifted behind the installed set (openai 1.74 vs 2.9, supabase 2.13 vs 2.27), so a
# clean Docker build would have deployed a stack nothing was tested against.
#
# To upgrade: change a pin deliberately, reinstall, and run the test scripts.

# API Server

# locally — only a clean build surfaced it.
